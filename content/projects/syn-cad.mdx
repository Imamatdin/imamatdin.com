Natural language to manufacturable STL files. Describe a part in plain English,
get OpenSCAD code back, automatically compiled and validated. Errors are fed back
to the LLM for correction. Includes CADBench for evaluating LLM-generated CAD
on format compliance, compilation, geometric accuracy, and parametric robustness.

**Stack:** Python, OpenSCAD, Groq/Gemini, LLM tool use
