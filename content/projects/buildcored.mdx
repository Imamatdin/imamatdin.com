An open-source builder community for creative engineering, run on four rules: build
every day, start with what you own, if it runs it counts, and read other people's code.
Everything is free and MIT licensed. 1,500+ members.

**Orcas v1.5** — a 30-day software cohort where 10 builders each shipped one project a
day using Python, locally-run models and webcam input. All 30 are open-source on GitHub.

**Orcas v2.0** — an in-person hardware cohort at Turin Polytechnic Lyceum in Tashkent,
15-24 August 2026, with hardware kits through a partnership with Nazarx Robotics.

**Stack:** Python, Ollama, webcam and gesture input, robotics hardware, GitHub
